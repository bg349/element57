# Element 57 Pool Co. website

Static one-page site for Element 57, a lanthanum chloride phosphate remover for pools and spas (working name).

- `index.html` is the whole site: inline CSS and JS, plus Anime.js and Apache ECharts from cdnjs, Lenis from jsDelivr and fonts from Google Fonts.
- Hosted free on GitHub Pages from the `main` branch root.
- Highlighted text on the page marks placeholders still to be filled in (name, prices, area, contact).
- The water background is a WebGL shader in `index.html`; it renders below screen resolution and lowers its quality automatically on slow devices.
