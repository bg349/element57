# Element 57 Pool Co. website

Static one-page site for a phosphate-first pool care business (lanthanum chloride treatment).

- `index.html` is the whole site: inline CSS and JS, plus Anime.js and Apache ECharts from cdnjs and fonts from Google Fonts.
- Hosted free on GitHub Pages from the `main` branch root.
- Highlighted text on the page marks placeholders still to be filled in (name, prices, area, contact).
